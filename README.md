# Kytky Plzeň: eshop a provozní systém

Vlastní eshop a provozní systém pro květinářství Kytky Plzeň (kytkyplzen.com), který nahradí Shoptet. Zákazník objedná kytici na konkrétní hodinu a adresu a zaplatí online, obsluha vše vyřídí z mobilu.

## Stav

Fáze 0 (návrh) čeká na schválení. Nic z aplikace zatím není naprogramované.

## Plán fází

1. Základ: katalog, admin denní nabídky, sklad.
2. Objednávka: sloty, cena dopravy, Stripe (testovací režim), doklady, notifikace.
3. Formulář pro Instagram a telefon, přehled objednávek, odkaz pro řidiče.
4. Věrnostní systém a režim Prodejna.
5. Migrace, SEO, spuštění.

Po každé fázi následuje preview URL, shrnutí a seznam k otestování. Pokračuje se až po výslovném schválení.
